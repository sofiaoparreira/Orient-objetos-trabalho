Tutorial: Introdução à Orientação a Objetos




DEFINIÇÃO


A Orientação a Objetos é um modo de organizar o desenvolvimento de um software por meio de objetos. Esses objetos são instâncias de classes e combinam dados (atributos ou propriedades) e comportamentos (métodos ou funções) relacionados.





CONCEITOS


OBJETOS


Uma coleção de dados (propriedades) e funcionalidades (métodos) que representa uma entidade. É uma instância de um tipo, embora em JavaScript, objetos possam ser criados diretamente sem a necessidade explícita de uma classe tradicional na sua sintaxe mais básica.

PROPRIEDADES



Atributos ou características de um objeto. Armazenam dados que descrevem o estado do objeto. São associações entre nomes (chaves) e valores.



MÉTODOS


Funções que estão associadas a um objeto e definem o comportamento ou as ações que o objeto pode realizar. São propriedades de um objeto cujo valor é uma função. Dentro de um método, a palavra-chave this geralmente se refere ao objeto ao qual o método pertence.




Exemplo 1
OBJETO: Humano

let humano = {
nome: "Sofia",
idade: 16,
profissao: "Programadora",
saudar: function() {
console.log(`Olá, meu nome é ${this.nome}.`);
}
};
console.log(humano);
humano.saudar();

Exemplo 2
FUNÇÃO: Multiplicação

function multiplicacao(num) {
return num * 2;
}
let result = multiplicacao(9);
console.log(result);
